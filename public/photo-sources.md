# Фотографии для дизайна «Маршрут открытий»

В итоговом макете использовано 68 уникальных реальных фотографий. Фото размещены без генеративной перерисовки; некоторые кадрированы. Пазл составлен из фрагментов фотографии. Все снимки получены из Wikimedia Commons. Они иллюстрируют места в момент съёмки и не подтверждают их современное состояние.

Скриншоты интерфейса — статический дизайн, игровые состояния показаны как примеры.

Для каждого фото указаны исходная страница, автор и лицензия. Лицензионные условия приведены по метаданным оригинала.
