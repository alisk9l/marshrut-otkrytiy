# Как работает сайт

«Маршрут открытий» — игра о пяти местах. Локацию можно выбрать на карте и пройти два разных мини-квеста: поиск объектов, викторину, пазл или другое задание.

После двух заданий игрок получает штамп в паспорт. За пять штампов открывается сертификат, который можно скачать в PNG. Прогресс сохраняется в браузере. Регистрация не нужна.

В заданиях ботанического сада, памятника Пушкину, художественного музея и степи музыку можно включить кнопкой «Музыка».

# Как запустить

Установите Node.js 22.12 или новее. Откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, который появится в терминале. Обычно это http://127.0.0.1:5173/.

Чтобы собрать готовый сайт и посмотреть результат:

```sh
npm run build
npm run preview
```

Готовые файлы сайта появятся в папке `dist/`.
